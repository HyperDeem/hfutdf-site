# 可公开需求摘要

依据维护者确认的 v1.2 与阶段 3A 安全整改决定编写。完整内部基线、审计和验收材料不随仓库公开。

- 名称：机械工程辩论队仓库；计划 GitHub Public 仓库名 hfutdf-site，尚未创建或推送。
- 首页：好的思考，值得被留下。保留现有蓝色强调，结构为宣言、目录、传承尾声。
- 七大入口依次为专业资料、图书资料、照片留影、比赛记录、辩论学习资料、辩论队工作材料、其他工具。
- 当前没有获准生产资料，显示正常空状态；虚构测试内容只在 tests/fixtures。
- 比赛记录保留中性介绍，不播放、不预览、不提供下载或外部下载链接；录像压缩包也暂停。
- 真实资料逐份审核，留在私有本地；不进 public、生产产物或公开 Git 历史。
- 原创代码按 MIT 授权，署名 HyperDeem，第三方材料与设计规范除外。
- 不增加后台、数据库、登录、评论、在线投稿或二级分类。
- Issues 与 Fork/PR 用于小规模协作；不给他人默认写权限，不连接自动部署。
- 当前所有工作限本地，后续建仓、push、采购云服务、绑定域名或发布网站需单独批准。
